2. **Shared Library** (Week 2)
   - Team video library
   - Shared clips
   - Team-wide tags

### Database
```sql
-- Teams & memberships
CREATE TABLE teams (
  id UUID PRIMARY KEY,
  name TEXT NOT NULL,
  created_by UUID REFERENCES auth.users
);

CREATE TABLE team_members (
  team_id UUID REFERENCES teams,
  user_id UUID REFERENCES auth.users,
  role TEXT, -- 'admin' | 'editor' | 'viewer'
  PRIMARY KEY (team_id, user_id)
);

-- Update videos/clips to support team ownership
ALTER TABLE videos ADD COLUMN team_id UUID REFERENCES teams;
ALTER TABLE clips ADD COLUMN team_id UUID REFERENCES teams;
```

## Risk Mitigation

### High-Risk Areas
1. **FFmpeg in Edge Functions** - May hit memory limits
   - **Mitigation**: Use smaller video chunks, stream processing
2. **Player Detection Accuracy** - Reka may not detect all players
   - **Mitigation**: Manual correction UI is critical
3. **Commentary Quality** - AI voices may sound robotic
   - **Mitigation**: Multiple voice options, editing interface
