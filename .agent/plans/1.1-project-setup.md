### 2. Initialize FastAPI Backend

**File**: `backend/main.py`

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
import uvicorn

app = FastAPI(
    title="Reka Sports Highlights API",
    description="AI-powered sports video highlight generation",
    version="1.0.0"
)

# CORS
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],  # Vite dev server
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.get("/")
async def root():
    return {"status": "ok", "message": "Reka Sports Highlights API"}

@app.get("/health")
async def health():
    return {"status": "healthy", "version": "1.0.0"}

if __name__ == "__main__":
    uvicorn.run("main:app", host="0.0.0.0", port=8000, reload=True)
```

```typescript
function App() {
  const [apiStatus, setApiStatus] = useState<string>('checking...')

  useEffect(() => {
    fetch('http://localhost:8000/health')
      .then(res => res.json())
      .then(data => setApiStatus(data.status))
      .catch(() => setApiStatus('error'))
  }, [])

  return (
    <div className="min-h-screen bg-gray-50 flex items-center justify-center">
      <div className="text-center">
        <h1 className="text-4xl font-bold text-gray-900 mb-4">
          Reka Sports Highlights
        </h1>
        <p className="text-gray-600">
          API Status: <span className="font-semibold">{apiStatus}</span>
        </p>
      </div>
    </div>
  )
}

export default App
```

## Troubleshooting

**Port conflicts**:
- Backend: Change port in `main.py` and frontend API URL
- Frontend: Change port in `vite.config.ts`

**CORS errors**:
- Check `allow_origins` in `main.py` matches frontend URL
- Verify frontend is making requests to correct backend URL

**Import errors**:
- Backend: Activate venv before running
- Frontend: Run `npm install` in frontend directory
